# Market Watch - cloud pilot v0.1

## Κατάσταση

Αυτή είναι δοκιμαστική βάση, όχι ενεργοποιημένος AI agent. Δεν έχει γίνει
deployment, σύνδεση ζωντανών δεδομένων, σύνδεση Telegram ή πραγματική αποστολή.
Το δείγμα PDF περιέχει μόνο συνθετικά δεδομένα και φανταστικές μετοχές.

Υλοποιημένα: έλεγχος ποιότητας/παλαιότητας κλεισμένων ωριαίων bars, EMA20/50,
RSI, ATR, στηρίξεις/αντιστάσεις προηγούμενων 20 bars, κανόνες trading,
PDF οριζόντιων σελίδων με γραφήματα, JSON αναφορά, προαιρετική αποστολή PDF
σε ένα συγκεκριμένο Telegram chat, Dockerfile και έλεγχοι ασφαλούς αποτυχίας.

Εκκρεμή: πάροχος τιμών, επιβεβαίωση συμβόλων και πλήρους σημερινής σύνθεσης
FTSE/ATHEX 25, οικονομικά στοιχεία, συλλογή/επαλήθευση ειδήσεων, AI σύνθεση,
επενδυτική αξιολόγηση 6-12 μηνών, βαθμολόγηση top picks, backtest με κόστη,
ημερολόγια συνεδριάσεων, αποθήκευση ιστορικού/μεταβολών, scheduling, monitoring,
retention αρχείων και επαλήθευση πραγματικής παραλαβής στο Telegram.

## Συμφωνημένος στόχος

- Ανεξάρτητη λειτουργία σε server, χωρίς ανοιχτό προσωπικό υπολογιστή.
- Ωριαίος έλεγχος και αποστολή μηνύματος + παρουσίασης PDF σε ομαδικό Telegram.
- Ελλάδα: FTSE/ATHEX 25 και ρητά οι METLEN, ΑΚΤΩΡ, TITAN, Εθνική,
  Eurobank, Alpha Bank, Πειραιώς, HELLENiQ ENERGY και Motor Oil.
  Η ονομαστική λίστα δεν ισχυρίζεται ότι όλες είναι σήμερα στον δείκτη.
- ΗΠΑ: MSFT, AAPL, GOOGL, AMZN, NVDA, AVGO, META, BRK-B, JPM, V, MA,
  JNJ, ABBV, WMT, COST, PG, KO, XOM, CVX, CAT.
- Ξεχωριστά BUY/SELL/HOLD ή αναμονή για trading ημερών-εβδομάδων και 6-12 μήνες.
- Trading: τάση, είσοδος, στηρίξεις, αντιστάσεις, στόχοι, stop, πιθανή ακύρωση.
- Μακροχρόνιο: αποτίμηση βάσει οικονομικών αποτελεσμάτων, δανεισμού, ταμειακών
  ροών και επιβεβαιωμένων εξελίξεων. Όχι παραγωγή θεμελιώδους στόχου από RSI.
- Κάθε αναφορά θα εμφανίζει ώρα τιμών, πηγές και καθυστερήσεις.
- Αρχική δοκιμή χωρίς πληρωμένα δεδομένα όπου επαρκούν, διαφορετικά χαμηλό
  κόστος που θα προσδιοριστεί μετά από έλεγχο κάλυψης. Δεν έχει εγκριθεί αγορά.

## Τοπικός δοκιμαστικός έλεγχος

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python agent.py --demo
```

Το demo δεν επιτρέπεται να σταλεί από την εφαρμογή. Δεν χρειάζεται κανένα token.
Τα επίπεδα τιμών είναι ενδεικτικά, οι κανόνες δεν έχουν backtest, και δεν
υπάρχει υπολογισμός επιτυχίας ή πιθανοτήτων.

## Συμβόλαιο εισόδου δεδομένων

Ο προσαρμογέας πραγματικού παρόχου θα γράφει ένα UTF-8 JSON snapshot:

```json
{
  "demo": false,
  "stocks": [{
    "name": "Issuer name",
    "symbol": "PROVIDER_SYMBOL",
    "bars": [{"time": "2026-10-19T13:00:00Z", "open": 100,
      "high": 101, "low": 99, "close": 100.5, "volume": 10000}],
    "news": [{"title": "Verified announcement", "published_at": "ISO8601",
      "url": "https://issuer.example/announcement"}]
  }]
}
```

Χρειάζονται τουλάχιστον 60 κλεισμένα ωριαία bars ανά μετοχή.
Το `time` σημαίνει ώρα ΤΕΛΟΥΣ του bar σε UTC. Όχι ανοιχτά κεριά.
Τα OHLC πρέπει να έχουν ενιαία προσαρμογή για εταιρικές πράξεις.
Αρνητικές/μη έγκυρες τιμές, διπλές ώρες, μελλοντικά ή παλιά δεδομένα δεν
παράγουν νέο σήμα. Το κλείσιμο αγοράς στο pilot εμφανίζεται ως παλαιότητα,
μέχρι να προστεθούν επίσημα ημερολόγια συνεδριάσεων.
Οι ειδήσεις απλώς εμφανίζονται: δεν έχουν ακόμη ταξινόμηση ή AI ανάλυση.

```sh
python agent.py --input /secure/snapshot.json
```

## Telegram και φιλοξενία

1. Δημιουργία bot στο https://t.me/BotFather με `/newbot`.
2. Προσθήκη στην επιλεγμένη ομάδα με δικαίωμα αποστολής αρχείων.
3. Καταχώρηση token μόνο ως secret της φιλοξενίας και επαλήθευση του chat ID.
4. Δοκιμή πραγματικών δεδομένων πριν από ενεργοποίηση αυτοματισμού.
5. Δοκιμαστική αποστολή και επιβεβαίωση σωστής ομάδας/παραλαβής.

Απαραίτητα περιβάλλοντα: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

```sh
python agent.py --input /secure/snapshot.json --send
```

Το Dockerfile εκτελεί μία εργασία και τερματίζει. Δεν περιέχει scheduler και
δεν μετατρέπει μόνο του το pilot σε υπηρεσία. Το τελικό cloud job θα καλεί
πρώτα τον προσαρμογέα δεδομένων και κατόπιν την παραγωγή/αποστολή, κάθε ώρα.
Δεν χρησιμοποιούμε στατικό snapshot για ωριαίες ζωντανές αναφορές.
Δεν έχει επιλεγεί ούτε αγοραστεί συγκεκριμένος server.

## Πριν από παραγωγική λειτουργία

Πρώτα επαλήθευση κάλυψης ελληνικών/αμερικανικών μετοχών, χρονικών σημάνσεων,
καθυστερήσεων και δικαιωμάτων χρήσης/αποστολής των δεδομένων από τον πάροχο.
Κατόπιν συνδέονται ειδήσεις και θεμελιώδη, προστίθεται AI με αναφορές σε πηγές,
και ελέγχονται backtest και ανεξάρτητη δοκιμή ιστορικών περιόδων χωρίς
μελλοντική πληροφορία. Το LLM δεν υπολογίζει τις τιμές δεικτών ή διαγραμμάτων.

Πηγές σχεδιασμού:
- https://core.telegram.org/bots/api#senddocument
- https://core.telegram.org/bots/features#botfather
- https://athens.euronext.com/en/market-data/data-services/real-time-feed/data-vendors

## Άμεσα στοιχεία που χρειάζονται

Λογαριασμός φιλοξενίας ή επιλογή παρόχου από τον χρήστη, λογαριασμός δεδομένων
με κατάλληλη κάλυψη, Telegram bot και επιβεβαιωμένη ομάδα. Τα μυστικά δεν
περιλαμβάνονται στον κώδικα, στο PDF, στο ZIP ή στην ομαδική συνομιλία.
